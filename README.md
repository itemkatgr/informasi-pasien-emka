# Website Informasi Pasien Rumah Sakit eMKA

File dalam paket:
- `index.html` — halaman responsif dengan desain seperti contoh.
- `logo-emka.png` — logo yang diberikan pengguna.

## Upload ke repository GitHub
Unggah `index.html` dan `logo-emka.png` bersama-sama ke folder utama repository. Pastikan nama file logo persis `logo-emka.png`.

## Aktifkan GitHub Pages
Repository → Settings → Pages → Build and deployment:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
Klik Save, lalu tunggu sampai URL website muncul.

## QR Code
Buat QR Code dari URL GitHub Pages yang sudah aktif, bukan dari salah satu link Google Drive.
